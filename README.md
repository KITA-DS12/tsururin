# ツルリン — 氷上スライドパズル挑戦状

スワイプした方向に、何かにぶつかるまで止まれずに滑る。ゴールには「ぴったり停止」。
毎日0時(JST)に全員共通の1問が出る **デイリーモード** と、自作問題をURLだけで配れる **挑戦状モード** を備えた、完全静的なWebゲームです。

- ログイン不要 / データベース不要 / サーバーサイド処理なし
- 全50ステージのステージモード(岩だけの入門から全ギミックの最難関まで、新タイルは登場ステージで解説)
- 5の倍数の「関門」ステージをクリアすると次の5ステージが一括解放(途中スキップ可能)
- エディタの「ランダム生成」で、解けることが保証された問題をワンクリック生成(難易度3段階)。そのまま挑戦状として公開も可能
- 成績・ストリークは端末の localStorage、問題データはURLハッシュに格納
- デイリー問題は日付シードからクライアント側で決定論的に生成(全員同じ盤面)
- 挑戦状は「作者本人がクリアした問題」しか発行できず、解いた側は作者の手数と勝負(「作者超え」)

## 動かし方

静的ファイルのみなので、任意の方法でホスティングできます。

```bash
# ローカル確認(どちらでも)
npx serve .
python3 -m http.server 8000
```

`index.html` をダブルクリックして file:// で開いても動作します(Webフォントのみネット接続時に適用)。

### デプロイ

本番環境は **S3 + CloudFront + Route 53** で `https://tsururin.mu-k.net` に配信。

```bash
make deploy   # S3 同期 + CloudFront キャッシュ無効化
```

事前に `.env` を作成し、AWS CLI でログイン済みであること。初回のインフラ構築手順は [`docs/DEPLOY.md`](docs/DEPLOY.md) を参照。

#### 他のホスティングを使う場合

ビルド工程はないため、`index.html` / `css/` / `js/` / `ogp.png` / `promo.png` を任意のホスティングに置けば動作する（Cloudflare Pages・GitHub Pages・Netlify など）。

## 仕組みのメモ

- **デイリーの同期**: `daily.js` が `'TSURURIN-v1-' + 日付` をシードに盤面を乱数生成し、ソルバーでPARが曜日の許容範囲に入るまで再試行します。アルゴリズムとシードが共通なので、全クライアントが同じ問題に到達します(サーバー配信不要)。生成は典型的に数ms〜数十msです。
- **挑戦状URL**: 盤面(1マス4bit)+作者手数+作者名+CRC16をbase64urlで `#c=...` に埋め込みます。9×9+作者名12文字で約110文字。改ざん・欠損はCRCで検出し「破損しています」と表示します。
- **ギミックの品質保証**: 矢印床を含む盤面は「最短解が実際に矢印で方向転換するもの」だけを採用します(飾りの矢印を排除)。ステージ・デイリー・ランダム生成すべてに適用。
- **公開ゲート**: エディタは (1) ソルバーで可解 かつ PAR3以上、(2) 作者本人のテストプレイクリア、の両方を満たさないとURLを発行しません。クリア不能問題の拡散を仕様で防ぎます。
- **PARの扱い**: デイリーではPARを表示しますが、挑戦状では作者にも挑戦者にも真のPARを見せません(「作者超え」の余地を残すため)。

## カスタマイズ

- **デイリーの起点日(#1の日付)**: `js/daily.js` の `EPOCH_UTC`(現在 2026-06-11 = #1。番号表示が変わるだけで、盤面は日付シード由来なので変わりません)
- **ステージの難易度カーブ**: `js/daily.js` の `stageCfg()`(帯域ごとのサイズ・ギミック・PAR範囲)と `NEW_TILES`(新タイル解説)、`CHECKPOINT`(関門の間隔)
- **ランダム生成の難易度**: 同ファイルの `randomCfg()` / `RANDOM_DIFFS`
- **曜日別の難易度**: 同ファイルの `CFG`(盤面サイズ・ギミック数・PAR範囲)
- **配色・フォント**: `css/style.css` 冒頭の `:root` トークン
- **OGP画像**: `ogp.png`(1200×630)を同梱済み。**デプロイ後に `index.html` 内の `og:image` / `twitter:image` の `https://your-domain.example/ogp.png` を実際の公開URLへ書き換えてください**(SNSのカード取得は絶対URLのみ対応のため)。画像を作り直す場合は `npm i sharp` の上で `node tools/ogp.js`
